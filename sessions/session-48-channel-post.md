## Body

```
I built chitra because every terminal-chart library I tried either pulled in a
dependency tree or printed ANSI soup that language models can't read.

It's a TypeScript library that renders 20 chart types as text — Braille, Unicode
blocks, or plain ASCII for SSH/logs. Zero runtime dependencies.

  npm install @ifelse.codes/chitra   (or: pnpm add @ifelse.codes/chitra)

  import { line } from "@ifelse.codes/chitra";
  line({ data: [12,19,14,27,22,34,29,41], title: "Weekly active users" }).render();

The part I care most about: agents. toPlain(), toContent() and toJSON() hand a
model the chart as clean structure — no ANSI escapes to strip, no box-drawing
noise to interpret. Same render, three audiences: a terminal, a CI log, a context
window.

Measured, and reproducible with one command (node scripts/gtm-bench.mjs):
  0 runtime dependencies
  81.5 KB tarball, 398.4 KB installed
  < 2 ms to render a 100-point line chart (median of 200 runs)

Docs: https://chitra.iifelse.com
Repo: https://github.com/ifelse-codes/chitra

Honest note: this has essentially no users yet. I'd rather measure that than
pretend otherwise — the README's numbers are all generated by scripts so nobody,
including me, can type a flattering one.
```
