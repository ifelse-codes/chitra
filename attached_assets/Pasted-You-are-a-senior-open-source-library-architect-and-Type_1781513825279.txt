# API Design

Simple API:

```ts
import { line } from "chitra";

console.log(
  line({
    data: [10,20,15,30,25]
  })
);
```

Advanced API:

```ts
import { plot } from "chitra";

plot(data)
  .line()
  .title("Revenue")
  .theme("tokyo-night")
  .render();
```
